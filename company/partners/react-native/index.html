React Native

Что такое React Native?

React Native – это фреймворк для создания кроссплатформенных приложений на языке JavaScript. Он позволяет писать приложения для IOS, Android и даже VR (на React VR можно создавать приложения для шлемов и очков виртуальной реальности»).

Создатель React Native – Facebook, лидер во front-end, компания, которая вкладывает огромные ресурсы в развитие своих технологий. Facebook активно развивает React и React Native, создает вокруг них целую инфраструктуру и мощное IT-сообщество.

Возможности React Native

React Native позволяет создавать мобильные приложения, используя при этом только JavaScript с такой же структурой, что и у React. Это дает возможность составлять многофункциональный мобильный UI с применением декларативных компонентов.

Еще одно преимущество технологии – быстрорастущее комьюнити из компаний, которые используют технологию, инвестируют в нее и поддерживают ее развитие: GeekBrains, Yandex, Airbnb, Wix, Tesla, Soundcloud, Walmart.

На этом фреймворке написаны UberEats, FacebookGroups и частично Instagram и Facebook.

Мы же с помощью данной технологии сделали мобильное приложение «СБС Мегамолл».
