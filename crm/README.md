# Учёт оплат клиентов

Внутренний инструмент: кто сколько должен и кто оплатил. Без сборки и сервера — открыть `index.html` в Chrome/Edge (при первом открытии нужен интернет: библиотека чтения Excel грузится с CDN).

- `app.js` — вся логика: импорт, распознавание плательщиков, расчёт долгов, экраны.
- `seed.js` — стартовый справочник клиентов: названия плательщиков из выписки и ключевые слова для узнавания.
- `seed.private.js` — контакты и заметки по клиентам. **Только локально**, в `.gitignore`. Без него всё работает, просто карточки без контактов.

## Как пользоваться
1. «Данные» → загрузить «Оплаты.xlsx» (листы вида «Октябрь 2026») — это начисления по месяцам.
2. Загрузить банковскую выписку из Эльбы (Деньги → выгрузка в Excel). Повторы пропускаются, ручная разметка сохраняется.
3. «Месяц» → «По клиентам» — кто оплатил месяц, кто нет. «Клиенты и долги» — сальдо и просрочка по всем.

Оплаты клиента гасят его самые старые начисления. Поступления делятся на «по плану», «разовая работа» (гасит строки «Разработка») и «долг прошлого периода» — по назначению платежа, тип можно поправить вручную.

Данные хранятся в браузере (localStorage). Регулярно сохраняйте копию: «Данные» → «Сохранить копию».
