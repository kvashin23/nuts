01

Шахматка квартир

Шахматка в строительной организации — один из основных инструментов менеджера по продажам. Важно, чтобы работа в ней было проста и удобна.

Чтобы структурировать информацию об актуальных объектах недвижимости, мы дополнили коробочную «Битрикс24» шахматкой. Жилой комплекс предстал в виде виртуальной модели, в которой хранятся данные о количестве этажей в каждом доме, метраже квартир, планировках, стоимости. Менеджеры компании могут отмечать, какие объекты недвижимости забронированы, какие проданы, а какие свободны.

Весь функционал мы разработали с нуля. Самое главное преимущество нашего продукта — невероятная гибкость разработки. В каждой компании годами складываются определенные бизнес-процессы и гораздо проще сделать систему под себя, чем работать в нескольких сервисах и тратить драгоценное время. Автоматизация процессов — это важно. Система работает, менеджеры продают.

По этой самой причине работа с такими сервисами как 1С:CRM, Profitbase и тд не подходит для внедрения в крупные строительные компании — в них ограниченность функционала, неудобный интерфейс, негибкость интеграций.

02

Зачем нужен сервис Шахматка в CRM?

  • Наглядность и оперативность. В момент обращения клиента менеджер может сразу отфильтровать и показать необходимые клиенту квартиры, применить опции и предоставить всю необходимую информацию.

  • Каталог квартир. Никаких табличек и реестров. Теперь актуальные данные о квартирах прямо в CRM. Например, можно отфильтровать двухкомнатные с определенной вилкой цен и нужными параметрами по всем объектам компании.

  • Уникальная экосистема для всех работников компании. Продажники, бухгалтеры, юристы работают в CRM и решают задачи в режиме одного окна. Вся информация сохраняется в сделке, т.е. по одному клиенту можно увидеть всё необходимое на одной странице — не нужно ничего искать. При этом можно получить всю информацию даже в мобильном приложении.

  • Гибкий функционал. Формирование коммерческого предложения, умный калькулятор скидок, предварительный график платежей — в вашей системе может быть любой функционал, который вам необходим. Есть калькулятор с опциями по квартире. Например, выбираем фурнитуру, отделку, умный дом и сразу сформируется скидку на комплект. Некоторые скидки могут применяться только при полной оплате сразу и тд. И все это прикрепляется к сделке. Т.е. менеджер работает в одной экосистеме и ему не нужно никуда переходить

Реализация шахматки

В рамках развития КИС строительной компании «Девелопмент Юг» было принято решение создать новую базу учета товарных остатков и API к ней, которые можно было бы использовать как основу для шахматки в CRM Битрикс24, а также для интеграций со сторонними системами и сервисами, потребность в которых начала возникать у клиента.

Данный вариант решения позволил организовать работу менеджера со всеми необходимыми ему в работе инструментами в рамках "одного окна", а также расширить функционал существующей шахматки дополнительными функциями, напр. изображениями планировок, калькулятором условий, формированием коммерческого предложения.

API в свою очередь, позволил решить вопрос обмена данными с сайтом, а также с сервисом ДомКлик от Сбербанка.

В дальнейшем шахматку планируется использовать в работе с риэлторскими агентствами, а также добавить функционал резервирования квартир клиентами самостоятельно.

Интерактивный каталог

  • Быстрый поиск объекта. Найти подходящую квартиру легко с помощью фильтров и разных видов отображения объекта.

  • Информативная карточка квартиры. В карточке объекта есть вся подробная информация о квартире, ценах и акциях.

  • История по каждой квартире. Просматривайте, как менялась история сделок по каждой квартире: брони, покупатели, менеджеры.

  • Быстрая работа в 2 клика. Добавляйте квартиры в сделки, распечатывайте и отправляйте планировки на email прямо из CRM.

03

Функционал шахматки

В карточке сделки можно добавить информацию о квартире через приложение «Шахматка». Сотрудник выбирает город, ЖК, фильтрует под необходимые параметры.

Для удобства выбора квартиры был реализован вид Шахматки Плитка+. На нём сразу видна цена, квадратура, код квартиры.

Поиск по планировкам. Возможен поиск по всем объектам компании. Реализована удобная навигация для возврата к результатам поиска от шахматки и наоборот.

Также калькулятор может рассчитать скидку или группу скидок. Опции, при этом, могут быть взаимоисключающими. Цены замазаны, так как информация по скидкам — это конфиденциальная информация.

Возможно связать несколько сделок в одну напрямую из шахматки. Это собственная разработка, поэтому функционал здесь не ограничен. В других же решениях разработка ведется в определенных рамках. Есть функционал и в его рамках приходится работать.

Любая доработка возможна — это лишь вопрос времени на разработку.

Что для этого нужно?

  1. 1С-программист в вашем штате, который сможет настроить интеграцию необходимой информации.

  2. Иметь работающую CRM Битрикс24 или AMO

  3. Мы разработаем API для взаимодействия сайта и CRM. API — так называемый “мост” для связи CRM и 1С.

  4. В 1С должны быть заполнены все необходимые данные по объектам: планировки, цены, опции и тд.
