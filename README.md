# NUTS — сайт агентства

Статичный сайт без сборки. Всё, что нужно для работы, лежит в проекте: библиотеки и шрифты — в `vendor/` (GSAP 3.12.5, ScrollTrigger, Lenis 1.1.13, Three.js r160, Unbounded + Manrope).

| Страница | Что это |
|---|---|
| `index.html` | Главная: 3D-орех, услуги, кейсы, процесс, о нас, блог, бриф |
| `case.html` | Шаблон кейса (на примере DOGMA) |
| `service.html` | Страница услуги (на примере «Разработка сайтов») |
| `blog.html` | Список статей с фильтром |
| `article.html` | Шаблон статьи (оглавление, прогресс чтения, врезки) |

Стили: `css/style.css` — общие и главная, `css/pages.css` — внутренние страницы. Скрипты: `js/main.js` — вся интерактивность (общая для всех страниц), `js/nut.js` — 3D-сцена главной.

Шапка и подвал одинаковые на всех страницах и продублированы в каждом файле — при переносе на CMS их стоит вынести в общий шаблон.

Локальный просмотр (Windows):

```
powershell -ExecutionPolicy Bypass -File server.ps1
```

и открыть http://localhost:5173
