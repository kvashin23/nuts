# NUTS — сайт агентства

Статичный сайт без сборки на сервере. Всё нужное лежит в проекте: библиотеки и шрифты — в `vendor/` (GSAP 3.12.5, ScrollTrigger, Lenis 1.1.13, Three.js r160, Unbounded + Manrope).

Опубликован на GitHub Pages: https://kvashin23.github.io/nuts/

## Страницы

| Путь | Что это |
|---|---|
| `index.html` | Главная: 3D-орех, услуги, кейсы, процесс, о нас, блог, бриф |
| `cases/` | Все кейсы (список с фильтром + страница каждого кейса) |
| `services/` | Все услуги: разделы и подуслуги |
| `blog/` | Список статей и сами статьи |
| `about.html`, `contacts.html` | О компании, контакты с брифом |

`case.html`, `service.html`, `blog.html`, `article.html` в корне — редиректы со старых адресов.

## Как устроено

- `css/style.css` — общие стили и главная, `css/pages.css` — внутренние страницы.
- `js/main.js` — вся интерактивность (общая для всех страниц), `js/nut.js` — 3D-сцена главной.
- `data/content.json` — контент кейсов, услуг и статей, импортированный со старого nuts-agency.ru; картинки к нему — в `assets/content/`.
- `data/custom/` — вручную оформленные страницы (кейс DOGMA, «Разработка сайтов», гайд о неэффективном сайте); генератор берёт их вместо автоматической вёрстки.
- `tools/build.js` — генератор: из `data/` собирает `cases/`, `services/`, `blog/`, `about.html`, `contacts.html` и обновляет ссылки на главной.

Сгенерированные страницы не правятся руками — правьте `data/` или шаблоны в `tools/build.js` и пересоберите.

## Локальный просмотр и пересборка (Windows)

```
powershell -ExecutionPolicy Bypass -File server.ps1
```

Сайт — на http://localhost:5173. Чтобы пересобрать страницы, во втором окне запустите

```
powershell -ExecutionPolicy Bypass -File tools/save-server.ps1 -Root .
```

и откройте http://localhost:5173/tools/build.html.

## Заявки с формы

Бэкенда у статичного сайта нет, поэтому форма брифа отправляет заявки на info@nuts-agency.ru через сервис FormSubmit (formsubmit.co). Адрес ящика и состав полей — в `js/main.js`, блок `brief form`.

Первая отправленная заявка вызовет письмо «Activate Form» на этот ящик. По ссылке из него форму нужно один раз подтвердить, иначе заявки приходить не будут.
